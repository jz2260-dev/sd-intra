Image and Configure Apple Device (Jamf)

SOP Flow

Confirm ADE and Jamf scoping first, complete setup assistant without shortcuts, wait for enrollment to finish, then validate reporting and ownership details.

Overview

Use this SOP for Apple devices enrolled through Jamf and Apple Device Enrollment.

Primary outcomeThe Apple device is fully enrolled, configured, validated, and assigned to the correct user and asset records.
Use whenA new or refreshed Apple device is being prepared through Jamf.
Do not use whenSerial registration, ADE scoping, or enrollment visibility is unresolved before setup begins.

Prerequisites

Confirm these before powering on the device.

Device serial is present in Jamf and properly scoped for Prestage Enrollment.

Onsite enrollment path uses Ethernet, not NYU Wi-Fi.

Required user assignment or provisioning details are available.

Any missing Jamf registration issue is resolved before setup starts.

Decision Points

Use these checks before and during enrollment.

Is the serial correctly scoped in Jamf?If not, stop and resolve scoping before powering on the device.
Did the Remote Management screen appear?If not, verify Ethernet and Jamf scoping before continuing.
Are you setting up for the user or as a technician?If technician credentials are used during setup, the Jamf record must be reassigned during cleanup.

Procedure

Standard Jamf enrollment and configuration sequence.

1
Verify Jamf readinessConfirm the serial is registered and properly scoped in Jamf before turning on the device. If missing, obtain the iBuy PO number and resolve registration first.
2
Prepare the network pathUse Ethernet for onsite enrollment. Offsite setups may use reliable home Wi-Fi or Ethernet.
3
Begin setup assistantPower on the device, select country and language, and continue through setup until the Remote Management screen appears.
4
Authenticate enrollmentEnter Stern or NYU credentials as appropriate to continue Jamf enrollment.
5
Create the user account correctlyCreate the account in the client's name using their NetID-based username and a temporary password format approved by the team.
6
Wait for Jamf configurationAllow profiles and applications to install without actively using the device, then restart when prompted and log back in.
7
Install any remaining appsOpen NYU Self Service and install required applications such as Adobe, Google Drive, VPN, or department-specific tools.

Validation and Closeout

Use these checks before handing off the device.

EnrollmentThe device appears correctly in Jamf inventory.
ProfilesRequired profiles and policies applied successfully.
ApplicationsCore and requested applications install and open correctly.
Security reportingJamf, KACE if applicable, Cortex XDR, and InsightVM are reporting.
User assignmentThe Jamf record reflects the correct user, department, and location.
Asset recordsKACE and Salesforce (E360) are updated as needed.

Escalation and Recovery

Escalate early when ADE or scoping issues block the standard path.

No Remote Management screenVerify network path and Jamf scoping, then escalate to Endpoint Management if it still does not appear.
Enrollment or profile application failsRetry only within the standard process, then escalate with serial, enrollment state, and exact failure point.
Serial registration is missingDo not continue setup until the registration issue is corrected.
