# Classroom Podium PC Login SOP

---

## Quick Start (Use This First)

Follow this checklist when assisting with a classroom podium PC login:

- [ ] Wake or power on podium PC
- [ ] Confirm correct login screen is displayed
- [ ] Have user enter Stern credentials
- [ ] Verify successful login
- [ ] Confirm network connectivity
- [ ] Test basic functionality (presentation, browser, etc.)

If login fails, go to the "Something Went Wrong" section.

---

## Step-by-Step (Use if You Need More Detail)

### 1. Power On / Wake Device

- Press power button or wake device
- Ensure monitor and peripherals are active

---

### 2. Confirm Login Screen

Verify:

- Windows login screen is displayed
- Device is connected to NYU Active Directory

---

### 3. User Login

Have user enter:

- **Username:** NetID
- **Password:** NYU password

---

### 4. First-Time Login (If Applicable)

If user has never logged into this PC:

- Allow time for profile creation
- This may take several minutes

---

### 5. Validate Login

Confirm:

- User successfully logs in
- Desktop loads properly
- No error messages appear

---

### 6. Basic Functionality Check

Verify:

- Internet access works
- Browser opens
- Presentation software (PowerPoint, etc.) launches
- Display/projector is working

---

### 7. Log Out (If Testing Only)

If testing:

- Log out after validation

---

## Escalation

If issues cannot be resolved:

- Escalate to **Endpoint Management**
- Include:
  - Classroom location
  - Device name (if available)
  - User NetID
  - Error message
  - Steps already performed

---

## Something Went Wrong (Quick Fixes)

| Issue | What to Check |
|------|---------------|
| User cannot log in | Verify credentials / AD account |
| “Other user” missing | Switch login option |
| Slow login | First-time profile creation |
| No network | Check Ethernet / Network SOP |
| PC frozen | Restart device |
| Projector not working | Check input/display settings |
| Urgent login issue | Use local account **.\tutor** to proceed |

---

## Done When

- User successfully logs in
- Network is working
- Presentation tools are functional
- No errors present

---

## Notes for Technicians

- Podium PCs are domain-joined (NYU Active Directory)
- First login may take longer than usual
- Always verify display/projector functionality
- If pressed for time (class/event about to start), use the local account: **.\tutor**
- Escalate to Endpoint Management if login issues persist

---

## Roles & Responsibilities

**Service Desk**
- Assist with login issues
- Validate functionality
- Perform basic troubleshooting

**Endpoint Management**
- Handle persistent login issues
- Resolve system or domain-related problems
